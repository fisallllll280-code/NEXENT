# NEXENT: From Impossible Idea to Actual Engineering

The system converts an extreme idea into a falsifiable engineering object rather than declaring novelty to be truth.

Transformation: idea -> hypothesis -> variables -> equations/model -> constraints -> falsifier -> simulation -> prototype -> measurement -> evidence -> verification -> governed deployment.

The executable layer records deployment, evidence attachment, planning, authorization, rejection, completion, and output in the existing hash-chained ledger.

Core separation: Idea != Model != Simulation != Prototype != Measurement != Evidence != Authorization != Reality.
