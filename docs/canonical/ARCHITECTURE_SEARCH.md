# NEXENT Architecture Search

Architecture search operates over a candidate space rather than selecting the first plausible design.

## Candidate generation

Capability Gap
→ constraints
→ known patterns
→ genome recombination
→ architecture candidates

## Evaluation dimensions

- functional fit
- correctness
- dependency burden
- complexity
- reliability
- recoverability
- security
- observability
- proofability
- resource cost
- evolution compatibility

## Required outputs

For each candidate:

- rationale
- genome
- topology
- contracts
- constraints
- risks
- simulation evidence
- verification status
- proof package
- lineage

No candidate becomes canonical solely because it has a higher heuristic score.
