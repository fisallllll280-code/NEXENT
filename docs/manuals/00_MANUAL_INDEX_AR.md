# NEXENT — فهرس كتيبات التشغيل

هذا المجلد هو حزمة التشغيل والنشر. كل كتيب مستقل ويمكن قراءته دون الاعتماد على كتيب آخر.

1. 01_INSTALL_AR.md — التثبيت والتهيئة.
2. 02_FULL_OPERATION_AR.md — دورة التشغيل الكاملة.
3. 03_SUBSYSTEM_OPERATION_AR.md — تشغيل المنظومات الداخلية وربطها.
4. 04_VERIFICATION_AR.md — الاختبارات والأدلة وحالة التحقق.
5. 05_RECOVERY_AR.md — الاسترداد، العزل، وإعادة التشغيل.
6. 06_RELEASE_AR.md — بوابة الجاهزية للنشر.
7. 07_STATUS_AND_LIMITS_AR.md — ما هو منفذ فعليًا وما هو مواصفة أو هدف.

قاعدة النشر: SPECIFIED ≠ IMPLEMENTED ≠ TESTED ≠ VERIFIED.
