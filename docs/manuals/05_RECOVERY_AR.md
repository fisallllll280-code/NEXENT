# NEXENT — كتيب الاسترداد

## عند فشل التشغيل
1. احتفظ بمخرجات الخطأ.
2. لا تحذف المصدر الفاشل.
3. حدّد النظام والالتزام commit الذي فشل.
4. افصل التغيير في فرع إصلاح.
5. أعد الاختبارات.
6. أضف الدليل إلى سجل النشر.

## العزل
أي مكوّن غير موثوق يوضع في حالة BLOCKED/QUARANTINED ولا يستخدم لإثبات جاهزية بقية المنظومة.

## الرجوع
الرجوع إلى آخر commit مثبت هو المسار الافتراضي. لا يتم تعديل التاريخ الأصلي للأدلة.
