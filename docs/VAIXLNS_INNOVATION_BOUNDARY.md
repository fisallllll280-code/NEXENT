NEXENT is kept as a separate system identity.

- architecture/system discovery
- candidate generation
- system graph construction
- governed capability execution
- evidence and replay
- innovation/evolution proposal flow

## VAIXLNS owns
- constitutional identity
- canonical system-of-systems architecture
- V / VV / VX / XV canonical relations
- sovereign governance and authority
- canonical registries and project lineage

## Integration contract
VAIXLNS Canon
-> Discovery Request
-> NEXENT Search / Candidate Generation
-> Evidence + Simulation + Verification
-> Candidate Proposal
-> VAIXLNS Governance Gate
-> Canonicalization or Rejection

NEXENT must not silently promote its generated candidate into VAIXLNS canonical reality.
