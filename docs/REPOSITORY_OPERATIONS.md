# Repository Operations Contract

Repository: `fisallllll280-code/NEXENT`

## Governed lifecycle

DISCOVER → CLASSIFY → INDEX → PLAN → MODIFY → TEST → REVIEW → PROVE → PR → MERGE → OBSERVE → RECOVER

## Federation role

This repository is operated as a member of the VAIXLNS/NEXENT repository federation. Changes must remain traceable to a commit/PR and must preserve repository-specific ownership.

## AI worker boundary

External AI providers, including the Fable worker, are workers only:
- authority: NONE
- no direct canonical governance
- no browser-held credentials
- no silent mutation of protected policy

## Operation record

Every automated operation should identify:
- target repository/ref
- operation
- actor/provider
- requested change
- evidence
- test result
- review state
- recovery path

## Completion

An operation is complete only after the relevant checks pass and the resulting commit/PR is traceable.
