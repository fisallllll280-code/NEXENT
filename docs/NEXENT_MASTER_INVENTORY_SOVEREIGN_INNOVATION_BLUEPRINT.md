# 4. STATUS MODEL

| Status | المعنى |
|---|---|
| CANONICAL | صياغة معتمدة داخل المرجع |
| PROTOTYPE | نموذج أولي أو تجربة تنفيذية |
| CONCEPT | مفهوم أو تصميم يحتاج توسعًا تنفيذيًا |
| DUPLICATE | مكرر أو مدمج تحت عنصر آخر |
| UNVERIFIED | موجود في المادة لكنه يحتاج تحققًا من الأرشيف |

### قاعدة مهمة

**CANONICAL في النص لا يعني إثباتًا خارجيًا مستقلًا.**

يجب الحفاظ على الفرق بين:

`Source-Asserted`

و

`Archive-Verified`

حتى لا يتحول الفهرس إلى ادعاء غير قابل للتدقيق.
