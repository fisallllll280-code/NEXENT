# NEXENT Status Model

| Status | Meaning |
|---|---|
| RECOVERED | found in source/archive |
| LEGACY | historical form retained for lineage |
| CANONICAL | current normalized form |
| MERGED | consolidated with another identity |
| PROPOSED | newly proposed design |
| IMPLEMENTED | implementation exists |
| VERIFIED | verification evidence exists |
| PROVEN | proof obligations satisfied |
| ADOPTED | accepted by target governance |
| DEFERRED | intentionally not adopted yet |
| REJECTED | reviewed and not adopted |

Status transitions must be explicit and traceable.
