# NEXENT → VAIXLNS Adoption Contract

NEXENT produces candidates; VAIXLNS governs adoption.

## Handoff package

1. Candidate architecture identity
2. Architecture/System Genome
3. Capability delta
4. Dependencies
5. Contracts
6. Authority requirements
7. Simulation results
8. Failure and recovery analysis
9. Evidence
10. Proof obligations and proof status
11. Lineage
12. Proposed adoption target

## Prohibited shortcut

A successful simulation is not automatic production authorization.

## Lifecycle

PROPOSED
→ SIMULATED
→ VERIFIED
→ PROVEN
→ GOVERNANCE_REVIEW
→ ADOPTED | REJECTED | DEFERRED

Rejected or deferred candidates remain in lineage unless explicitly archived.
